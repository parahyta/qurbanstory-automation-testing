# Qurban Story Automation Testing

End-to-end automation testing project for Qurban Story using Selenium, Cucumber, and Maven.

## Technologies
- Java
- Maven
- Selenium
- Cucumber
- TestNG

## Testing Scope
This project focuses on Black-Box Testing and BDD scenario testing for the following pages:
- Landing Page
- Login Page
- Product Page
- Checkout Page
- Invoice Page

## Project Structure
src/test/java
- stepdefinitions
- pages
- runners

src/test/resources
- features

## Implemented Testing
- Equivalence Partitioning (EP)
- Boundary Value Analysis (BVA)
- Behavior Driven Development (BDD)

## Feature File
The project includes end-to-end Gherkin scenarios for qurban purchase flow testing.
